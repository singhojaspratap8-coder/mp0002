# LocalDrop ⚡
Fast & Secure File Sharing Tool for Termux & Linux.
Created by **Ojas Pratap Singh**.

## How to Install in Termux:
Run the following commands in your Termux:
```bash
pkg update && pkg install git -y
git clone [https://github.com/singhojaspratap8-coder/localdrop.git](https://github.com/singhojaspratap8-coder/localdrop.git)
cd localdrop
bash setup.sh
